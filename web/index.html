How it works

      
Three decisions shape everything else.

    

    

      

        
The forecast is polled, never fetched mid answer

        

          NOAA is read on a background timer every fifteen minutes and held in memory, so an answer is a few
          milliseconds of arithmetic. A voice turn has roughly half a second in total, which a live call to an external
          service can eat on its own.
        

      

      

        
The verdict is drift against tolerance, not a Kp number

        

          Expected error comes from the correction the machine runs, RTK, PPP, SBAS or none, the geomagnetic latitude of
          the site rather than its map latitude, and the distance to the RTK base. That is compared against what the job
          itself needs, which is why planting and tillage get different answers from the same sky.
        

      

      

        
Same storm, twelve different jobs

        

          One forecast means planting waits, a satellite team defers a manoeuvre, a control room watches transformer
          heating, a dispatcher plans a lower latitude route and an aurora watcher goes outside. Each gets its own
          steps, timed to how far off the storm is.
        

      

    

  


  

    

      
What it will not do

      
The honest list, because a wrong go-ahead costs a season.

    

    
    
      
  • It will not guess. If NOAA is unreachable it says so and tells you where to look instead.
    • 
      
  • It cannot speak first. An add-on answers when it is called, so watched jobs and storms are sent to the crew by email instead.
    • 
      
  • It stops at three days. That is how far the Kp forecast runs, and past it the answer is that it does not know.
    • 
      
  • It is not a base station. It tells you whether accuracy holds, it does not correct anything.
    • 
      
  • The stand-in farm is temporary. It belongs to this browser and is cleared when the server restarts.
    •

Run it yourself

      
Node 20 or newer. No keys, no accounts, no paid services.

    

    
git clone https://github.com/nirbhay221/orbita
cd orbita
npm install
npm run build
node dist/server.js        # serves this page and the MCP endpoint on 8788

    
Or, with nothing installed but Docker: docker build -t orbita . && docker run -p 8788:8788 orbita

    
Call a tool the way a host would:

    
curl -s http://localhost:8788/mcp \
  -H 'content-type: application/json' \
  -H 'accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"storm_status","arguments":{}}}'
